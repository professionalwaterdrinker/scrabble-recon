How racks are worked out

Each player starts with 7 tiles and draws as many as they play. Every tile a player puts down had to be drawn before that move. The app considers every draw order that fits, as if from a well-shuffled bag, and shows how often each tile was on the rack. Tiles marked certain were on the rack in every possible order: the ones played that turn, ones later plays forced onto the rack, and everything once the bag is empty. Tiles never played can only be named when the game finished with one player going out. This assumes the rebuilt order is right and that nobody passed or exchanged tiles.

The end-of-game adjustment is added only when the rebuilt game shows who used their last tile, so totals can differ from the score sheet.

Word list

Words are checked against ENABLE. This list is used for checking the board, rebuilding games, practice games and Quackle's suggestions.

ENABLE is free and built in, and close to the North American tournament list. To use Collins Scrabble Words (CSW24) or another list, load it from a copy you're entitled to use, as a text file with one word per line (anything after the first word on a line is ignored). The file stays in this browser. It is never uploaded or published.
